# Чек-лист ревью: фронтенд

Что смотреть в изменённых строках и вокруг них. ID — правила из
`docs/PR-POLICY.md`; подробности — в `AGENTS.md` и `docs/FRONTEND.md`.
Бери пункты по затронутым слоям.

## Роутинг (`app/`) — FE-ARCH-2, FE-AUTH-1

- `page.tsx` — реэкспорт экрана из `@/views/<page>` и метаданные. Запрос,
  `useState`, разметка, `"use client"` в `page.tsx` — BLOCKER.
- Новая страница лежит в правильной группе: публичная — `(site)`, для
  сотрудников — `(admin)`.
- Страница `(admin)` защищена серверной проверкой роли (layout группы или
  proxy), а не только скрытием ссылки в меню.

## Слои и слайсы — FE-ARCH-1, FE-ARCH-3

- Импорт только вниз: `features` не тянет `widgets`, `entities` не тянет
  `features`, `shared` не тянет ничего выше.
- Слайсы одного слоя не импортируют друг друга (`features/cart` →
  `features/auth-login` — нельзя; общее — вниз, в `entities` или `shared`).
- Импорт слайса — `@/entities/order`, не `@/entities/order/ui/OrderCard`.
- В `index.ts` — только то, что нужно снаружи.
- Сущность использует соседнюю — через `@x`.
- `"use client"` стоит в листовом компоненте, а не в экране целиком; в
  клиентский компонент не импортируется серверный код (секреты, `next/headers`).

## Данные (`api/`) — FE-DATA-1, FE-DATA-2, FE-HTTP-1

- Запрос — функция в `api/` слайса через клиент `shared/api`; голого `fetch`
  в компоненте нет.
- Тип ответа — из сгенерированной схемы; ручных интерфейсов с формой ответа
  и `as` на ответ нет.
- Ключи — из фабрики `xxxKeys`; литерал `queryKey: ['…']` — BLOCKER.
- Мутация инвалидирует всё затронутое: создание заказа → список заказов
  клиента и очередь бариста; правка позиции меню → список меню и деталь.
- Тост результата — в хуке мутации.
- `enabled` у запроса с необязательным параметром.
- Публичная страница с данными: prefetch на сервере + `HydrationBoundary`.

## Авторизация — FE-AUTH-1, G-3

- Токен не читается из cookie в JS, не кладётся в `localStorage`/zustand.
- Запросы с `credentials: "include"` — через общий клиент.
- Роль на фронте — только для отображения; решение о доступе — 403 с API.

## UI — FE-UI-1/2/3

- Цвета: `bg-background`, `text-foreground`, `text-primary`, `text-copper`;
  `#1C1A18`, `bg-[#…]`, `text-neutral-500` в новом коде — WARNING.
- Шрифты: заголовки `font-heading`, текст — по умолчанию.
- Отступы кратны 8px (`2`, `4`, `6`, `8` в Tailwind).
- Mobile-first: базовые классы — для телефона, `md:`/`lg:` расширяют; нет
  фиксированных ширин, ломающих 320px.
- Экран с запросом: скелетон, пустое состояние, ошибка; кнопка отправки
  `disabled` на `isPending`.
- `next/image` с осмысленным `alt`; кнопка — `<button>`, ссылка — `<Link>`.
- shadcn-компонент взят из `@/shared/ui`, а не написан заново.

## Компоненты и хуки — FE-HOOK-1, FE-SIZE-1

- Компонент не объявлен внутри компонента.
- `useEffect` — только подписка/сокет/таймер/DOM и с очисткой; производное
  состояние — вычислением при рендере.
- GSAP — через `useGSAP` со `scope`; `registerPlugin` не в компоненте.
- Компонент > 300 строк — WARNING, > 400 — BLOCKER.
