# Cofelier — обзор проекта

> Файл одинаковый в `cofelier-frontend/docs/` и `cofelier-backend/docs/`.
> Правка — сразу в обоих.

Cofelier (coffee + atelier, пишется с одной f) — веб-приложение кофейни-мастерской
со своей обжаркой. Слоган — «Мастерская вашего кофе». Публичный сайт для
клиентов и панель для сотрудников с разделением ролей. Проект для портфолио
fullstack-разработчика, может стать основой реальной кофейни.

Первая версия: публичный сайт с меню, вход и роли, управление меню, предзаказ
и панель заказов для бариста. **Онлайн-оплаты нет** — заказ оплачивается при
получении. Цены — в тенге.

## Репозитории

Два отдельных git-репозитория в одной локальной папке `cofelier/`:

| Каталог | Что | Стек |
| --- | --- | --- |
| `cofelier-frontend/` | сайт и админка | Next.js 16 (App Router), Tailwind 4, FSD, shadcn/ui, TanStack Query |
| `cofelier-backend/` | REST + WebSocket API | NestJS 11, Prisma, PostgreSQL |

Браузер → Next.js (`:3000`) → API на NestJS (`:4000`) → PostgreSQL через
Prisma. Типы API на фронте генерируются из Swagger бэкенда
(`openapi-typescript`), руками не пишутся.

## Роли

Права проверяются **на сервере** (guard + декоратор ролей). Скрытая кнопка на
фронте — только удобство, не защита.

| Роль | Код | Что может |
| --- | --- | --- |
| Клиент | `client` | смотреть меню, делать предзаказ, видеть историю своих заказов |
| Бариста | `barista` | видеть очередь заказов, менять статус: принят → готовится → готов |
| Менеджер | `manager` | редактировать меню и цены, вести стоп-лист, смотреть продажи |
| Админ | `admin` | управлять сотрудниками и их ролями, доступ ко всему |

## Статус заказа

`new` (создан клиентом) → `accepted` (принят) → `preparing` (готовится) →
`ready` (готов) → `completed` (выдан). Отмена — `cancelled`. Статус меняет
только персонал; клиент видит его в личном кабинете.

> Имена статусов и ролей в коде — предложение; окончательно фиксируются
> в Prisma-схеме на этапах 3 и 5 и затем правятся здесь.

## Этапы

Каждый этап заканчивается рабочим результатом, который можно показать.

| # | Этап | Результат |
| --- | --- | --- |
| 1 | Каркас | два проекта, Docker с PostgreSQL, CI с линтером и проверкой типов |
| 2 | Меню | API чтения меню и публичный сайт на этих данных |
| 3 | Вход и роли | регистрация, JWT в httpOnly-cookie, guards, разделение `(site)` / `(admin)` |
| 4 | Админка меню | создание, правка, цены, стоп-лист |
| 5 | Заказы | корзина и оформление у клиента, живая панель у бариста |
| 6 | Деплой | сборка образов, автодеплой по пушу в `main` |
| 7 | Доводка | тесты, статистика продаж, анимации GSAP, 3D (Three.js) |

Текущий этап отмечается в `AGENTS.md` каждого репозитория.

## Чего нет (и не делать без решения)

- Онлайн-оплаты, доставки, программы лояльности.
- Мультиязычности: интерфейс только на русском.
- Нескольких точек кофейни.
